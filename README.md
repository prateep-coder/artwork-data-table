# Artwork Data Table - React Internship Assignment

A React application built with TypeScript and Vite that displays artwork data from the Art Institute of Chicago API with server-side pagination and persistent row selection.

## 🚀 Live Demo

https://artwork-data-table1.netlify.app/

## 📋 Assignment Requirements

### ✅ Implemented Features
- [x] React + TypeScript + Vite project setup
- [x] PrimeReact DataTable component
- [x] Server-side pagination
- [x] Row selection with checkboxes
- [x] Custom row selection panel
- [x] Persistent selection across pages
- [x] No data prefetching from other pages

### 🛠️ Technical Stack
- **Frontend**: React 19, TypeScript, Vite
- **UI Components**: PrimeReact, PrimeFlex, PrimeIcons
- **HTTP Client**: Axios
- **API**: Art Institute of Chicago API
- **Deployment**: Netlify

## 🎯 Features

### Data Table
- Display artwork data with columns: Title, Place of Origin, Artist, Inscriptions, Start Date, End Date
- Server-side pagination for optimal performance
- Sorting and filtering capabilities

### Row Selection
- Individual row selection with checkboxes
- Select all/deselect all on current page
- Custom selection panel for bulk operations
- Persistent selection across page navigation

### User Experience
- Responsive design for mobile and desktop
- Loading states during API calls
- Toast notifications for user feedback
- Clean and intuitive interface
